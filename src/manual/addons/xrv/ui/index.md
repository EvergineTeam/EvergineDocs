# UI

---

![Windows and dialogs](images/windows_system_main.jpg)

XRV includes UI building blocks that give every module the same look and behavior: floating windows, alert and confirmation dialogs, notifications, and tabbed panels. They are built with MRTK controls and follow the colors and fonts of the [themes system](../themes.md).
