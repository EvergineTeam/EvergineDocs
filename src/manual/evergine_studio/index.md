# Evergine Studio

![Evergine Studio with a scene open](Images/evergineStudio.jpg)

**Evergine Studio** is the editor of Evergine. It is where you import and create assets, compose scenes from entities and components, configure the platforms your application targets, and run the result. Your C# code and Evergine Studio work on the same project: the components, scene managers and services you write in Visual Studio appear in the editor as soon as the project is built.

This section describes the editor itself. The concepts it edits (scenes, entities, components, materials, and so on) are explained in [Basics](../basics/index.md) and in the section of each feature.
