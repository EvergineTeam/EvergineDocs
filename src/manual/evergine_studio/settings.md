# Project Settings

---
**Project Settings** provide a centralized place to configure settings that affect the entire Evergine application.

Unlike scene-specific settings, these options are defined at the project level and apply globally across the application.

From Project Settings, you can configure features such as **Project Profiles**, **Services**, and other application-wide settings.
