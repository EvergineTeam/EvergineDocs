    Class ObjectIdDrawer

    Draws one kind of render object into an object ID target for the ObjectIdRenderer.

    Syntax
    public abstract class ObjectIdDrawer : DisposableObject
    Remarks

    A drawer is used, once per frame or more: Clear(), TryAdd(RenderObjectInfo, uint) for the objects, Prepare(CommandBuffer, in ObjectIdView) and CollectBarriers(List<Barrier>, List<Barrier>) outside a render pass, and Draw(CommandBuffer) inside it. The pixels it writes hold the object identifier and, in the second channel, the bits of the depth.
