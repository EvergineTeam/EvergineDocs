    Syntax
    public class CharacterController : Component, IDependencyObject
    Remarks

    This is not a rigid body. A character is moved by setting the velocity it wants, and the simulation slides it along walls, up steps and down slopes instead of applying forces to it. That is what makes character motion feel deliberate rather than physical, and it is why a body cannot be used for the job.

    The character is stepped inside the fixed physics step, before the bodies, so what it pushes reacts on the same step. It carries an optional inner body so that queries, contacts and other bodies can see it: without one it is invisible to everything except its own collision checks.

    Orientation

    Gets or sets which way the character faces.

    Declaration
    public Quaternion Orientation { get; set; }
    Property Value
    Type Description
    Quaternion
    Remarks

    This turns the character's own shape, which matters as soon as that shape is not a capsule: a box or a tapered shape shoulders through a gap differently depending on which way it points. For a plain capsule it changes nothing, since a capsule looks the same from every side.

    It is not the same as Up, which says which way the character stands rather than which way it looks, and it does not touch the orientation of the entity's transform: what the character faces and what its visual faces are left as two separate decisions, since game code usually drives the second one from a camera.
