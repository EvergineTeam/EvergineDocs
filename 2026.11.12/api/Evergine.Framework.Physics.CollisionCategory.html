    Enum CollisionCategory

    Identifies the collision category a physics body belongs to.

    Namespace: Evergine.Framework.Physics
    Assembly: Evergine.Framework.dll
    Syntax
    [Flags]
public enum CollisionCategory : uint
    Remarks

    A body belongs to exactly one category, and the PhysicsManager holds the matrix that decides which categories interact with each other. Queries, on the other hand, accept any combination of categories as a filter mask.
