    Syntax
    public class WheeledVehicleController : VehicleController, IDependencyObject
    Remarks

    The engine drives the configured front and rear differentials, each of which splits its share of the torque between the valid wheel indices assigned to that axle. Indices refer to the depth-first order of the VehicleWheel components below the chassis; a negative value leaves that side unassigned.
