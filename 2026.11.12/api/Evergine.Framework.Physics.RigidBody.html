    public class RigidBody : PhysicsBody, IDependencyObject
    Remarks

    A single component covers both movable kinds, selected with IsKinematic, which lets a body switch between them at run time. A body that never moves is a StaticBody instead: it has none of the settings this class exposes, since none of them mean anything for something that never moves.

    The shape comes from the Collider components found on this entity and its descendants. A body with no collider is still valid, it just cannot collide with anything.

    InertiaMultiplier

    Gets or sets how much harder than its shape suggests this body resists being turned.

    Declaration
    [RenderPropertyAsFInput(MinLimit = 0.0001, ShowConditionFunction = "IsDynamic", Tooltip = "How much harder than its shape suggests the body resists turning. One leaves it alone.")]
public float InertiaMultiplier { get; set; }
    Property Value
    Type Description
    float
    Remarks

    One leaves the inertia as the shape works it out, which is right for anything that is what it looks like. Above one makes a body harder to spin and to tip without making it heavier: a crate weighted at the bottom, a flywheel, a vehicle that should not roll over as readily as its box says it would. Below one makes it spin more freely than its shape allows.

    This is what Evergine offers in place of setting an inertia tensor outright, which is what the Bullet physics had. One number covers what that was nearly always used for, and it cannot describe a body that resists turning about one axis and not another.

    Read when the body is created, so changing it needs the body rebuilt.

    Mass

    Gets or sets the mass of the body, in kilograms. Zero computes it from the collider volumes and their density.

    Declaration
    [RenderPropertyAsFInput(MinLimit = 0, DesiredChange = 0.1, DesiredLargeChange = 1, ShowConditionFunction = "IsDynamic", Tooltip = "Mass in kilograms. Zero computes it from the collider volumes and densities.")]
public float Mass { get; set; }
    Property Value
    Type Description
    float
    Remarks

    Setting and getting are not quite the same thing here. Setting overrides what the shapes would work out, and setting zero hands the decision back to their density. Getting asks the simulation what the body actually weighs, so a body left to work its own mass out reports what it worked out rather than the zero it was given. A kinematic body, which weighs nothing as far as the solver is concerned, reports the number that was set.

    Only a dynamic body with colliders is asked, and even then the answer is only used when it is above zero. A dynamic body whose colliders are all mesh shapes ends up with an empty shape and no mass at all, and reporting the zero that comes back from that would lose the number the body was given.

    ApplyBuoyancy(Vector3, Vector3, float, float, float, Vector3, float)

    Pushes this body up as a fluid would, for one step.

    Declaration
    public bool ApplyBuoyancy(Vector3 surfacePosition, Vector3 surfaceNormal, float buoyancy, float linearDrag, float angularDrag, Vector3 fluidVelocity, float deltaTime)
    Parameters
    Type Name Description
    Vector3 surfacePosition

    Any point on the surface of the fluid.
    Vector3 surfaceNormal

    Which way is up out of the fluid.
    float buoyancy

    The density of the fluid over the density of this body. One neither floats nor sinks, above one floats.
    float linearDrag

    How much the fluid slows the body down. Around half is a reasonable start.
    float angularDrag

    How much the fluid stops it turning.
    Vector3 fluidVelocity

    How fast the fluid itself is moving, which is what a current is.
    float deltaTime

    The length of the step this is being applied for.
    Returns
    Type Description
    bool

    true when any part of a dynamic body was under the surface; otherwise, false.
    Remarks

    Call this from inside the fixed step, once per step, for every body that is in the fluid. It works out how much of the shape is under the surface and pushes accordingly, so a shape half in the water is pushed half as hard, and it applies the drag that makes something moving through water slow down and stop wobbling.

    There is no fluid density here, only buoyancy, which is the ratio between the density of the fluid and the density of the body: one for something that neither floats nor sinks, more than one for something that floats. That ratio is also the answer to where it settles, since a body floats with one over the ratio of itself submerged: something twice as light as water floats half out of it.
