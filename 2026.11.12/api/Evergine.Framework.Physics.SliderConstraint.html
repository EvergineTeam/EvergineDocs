    Class SliderConstraint

    Lets a body slide along a single axis while keeping its orientation, with optional limits, friction and a motor. Lifts, drawers and pistons are sliders.

    Remarks

    Distances and velocities here are measured along Axis, so a positive target moves the body in the direction the axis points. The native constraint measures the opposite way round, because it reports where the other body sits relative to this one, so every value crossing that boundary is negated.
