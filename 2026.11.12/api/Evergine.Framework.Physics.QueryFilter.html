    Struct QueryFilter

    Narrows down which bodies a query is allowed to hit.

    Namespace: Evergine.Framework.Physics
    Assembly: Evergine.Framework.dll
    Syntax
    public struct QueryFilter
    Remarks

    The default value of the struct is a filter that hits every solid body and skips sensors, which is what a query usually wants. A zero CategoryMask therefore means every category rather than none.
