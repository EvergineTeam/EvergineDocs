    Struct CollisionInfo

    Describes a contact between two bodies, as reported by the collision events of PhysicsBody.

    Namespace: Evergine.Framework.Physics
    Assembly: Evergine.Framework.dll
    Syntax
    public readonly struct CollisionInfo
    Remarks

    This is a value type on purpose. Contacts are produced by the simulation on worker threads and are dispatched later on the main thread, so handing out a mutable shared instance would force callers to copy anything they want to keep. A struct removes that rule: the value can be stored as is.
