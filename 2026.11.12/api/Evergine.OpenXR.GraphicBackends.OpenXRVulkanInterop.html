    Class OpenXRVulkanInterop

    What the Vulkan graphics context needs to be created for an OpenXR runtime: the extensions to enable and the methods that create the Vulkan objects. Obtained from InitializeForVulkan().

    Remarks

    The method signatures match the callbacks of Evergine.Vulkan.VKGraphicsContextOptions, so they can be assigned directly. With XR_KHR_vulkan_enable2 the runtime creates the instance and the device; with XR_KHR_vulkan_enable they are created with Vulkan directly and the runtime only picks the GPU.
