    Class ObjectIdRenderer

    Renders render objects into an integer render target where every covered pixel holds the identifier given to the object that covers it. Used to draw outlines and to pick objects.

    Remarks

    Every object is drawn by the first ObjectIdDrawer that accepts it. Billboards and the meshes whose effect has an ObjectId pass draw themselves with that pass, so they keep the geometry and the transparency of their effect, like the alpha test, line alignment or particles. The other meshes are drawn opaque with the object ID effect. Multiview draw contexts are not supported.

    The pixels hold the identifier and the depth: a IdPixelFormat target keeps the identifier and an IdDepthPixelFormat target keeps both.

    Usage, any number of times per frame: Clear(), Add(RenderObjectInfo, uint) for every object, Prepare(CommandBuffer, Matrix4x4, Camera, OutputDescription) and ApplyBarriers(CommandBuffer) outside a render pass, and Draw(CommandBuffer) inside a render pass whose framebuffer matches the output description and is cleared with TargetClearValue.
