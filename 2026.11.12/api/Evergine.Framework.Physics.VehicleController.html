    Class VehicleController

    Base class of the vehicles. Turns the body on this entity into a chassis driven by the VehicleWheel components found on its descendants.

    Syntax
    public abstract class VehicleController : Component, IDependencyObject
    Remarks

    A vehicle is a single constraint solved against the ground rather than a body per wheel. That is what keeps a car stable at speed, and it is why the wheels here are not bodies and never collide with anything themselves.

    The constraint registers itself as a step listener, so the powertrain runs inside the simulation step rather than between frames.

    ClutchStrength

    Gets or sets how hard the clutch couples the engine to the wheels.

    Declaration
    [RenderPropertyAsFInput(MinLimit = 0.01, DesiredChange = 0.5, DesiredLargeChange = 2, Tooltip = "How hard the clutch couples the engine to the wheels. Lower launches softer without wheelspin.")]
public float ClutchStrength { get; set; }
    Property Value
    Type Description
    float
    Remarks

    The torque the clutch passes is this figure times the difference in speed between the engine side and the wheel side, so a stiff clutch on a revving engine slams a large torque into the wheels the instant it engages and spins them up. Lowering it makes the car pull away without lighting up the tyres, at the cost of a slower launch.

    GearRatios

    Gets or sets the gear ratios of the gearbox, first gear first.

    Declaration
    public float[] GearRatios { get; set; }
    Property Value
    Type Description
    float[]
    Remarks

    These multiply the engine torque on its way to the differentials, so they decide how much force reaches the ground in each gear far more than the engine does: a first gear of five turns the same engine into something that climbs. The defaults are the simulation's own, which are spaced for a car with a light body and no low range.
