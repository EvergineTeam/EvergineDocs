    Class HeightFieldCollider

    A terrain built from a square grid of heights. Far cheaper than a triangle mesh for the same ground, both in memory and in query cost.

    public class HeightFieldCollider : Collider, IDependencyObject
    Remarks

    Heights are provided from code with SetHeights(float[], uint). The sample count must be a power of two, which is what the acceleration structure is built around. Only static and kinematic bodies can use it.

    Remarks

    The rectangle must be aligned to the internal block size, position and size both multiples of it. Heights are quantized into the range the shape was built with, so terrain meant to be raised later needs that headroom in the grid it was created with. Before the body exists the region is folded into the stored grid and the shape is built with it later.
