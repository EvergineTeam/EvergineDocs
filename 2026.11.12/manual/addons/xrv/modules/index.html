    XRV modules

    Modules are reusable features that plug into XRV. Each one is an Evergine add-on that you install from the Add-ons Manager and then register in your XrvService with AddModule. A module can add a button to the hand menu, tabs to the settings and help windows, and its own windows and entities. The XRV samples project runs all the public modules together.

    var xrv = new XrvService()
    .AddModule(new RulerModule())
    .AddModule(new PainterModule());
    Module Add-on What it does
    Image Gallery Evergine.Xrv.ImageGallery Shows images from a storage repository, one at a time.
    Model Viewer Evergine.Xrv.ModelViewer Loads 3D models from storage repositories and lets the user move, rotate, and scale them.
    Painter Evergine.Xrv.Painter Draws 3D lines in space with different colors and thicknesses.
    Ruler Evergine.Xrv.Ruler Measures the distance between two points.
    Streaming Viewer Evergine.Xrv.StreamingViewer Shows a video stream from an MJPEG source, such as an IP camera.
    Audio Notes Evergine.Xrv.AudioNotes Records audio notes and plays them back.
